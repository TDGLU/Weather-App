# Weather App
- This weather app allows users to search up weather status for any city they search for
- This weather app provides a 5-day forecast 

# Live site
https://tdglu.github.io/Weather-App/

Pushes to `main` automatically deploy via GitHub Actions. In the repo, open **Settings → Pages** and set **Build and deployment** source to **GitHub Actions** if the site is not live yet.
